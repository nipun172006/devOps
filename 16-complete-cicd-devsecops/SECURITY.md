# Security policy

## Supported version

The current `1.x` release is supported for this learning project.

## Reporting a vulnerability

Do not open a public issue containing exploit details or credentials. Report
the affected component, reproduction steps, expected impact, and suggested
remediation privately to the repository owner.

## Response process

1. Confirm and classify the report.
2. Revoke or rotate any exposed credential immediately.
3. Prepare and test a fix.
4. Repeat SAST, SCA, secret, and container scans.
5. Publish the corrected release and document the resolution.

Never commit a real key or token for demonstration purposes.
